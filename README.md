# Meiyuan6 Booking Admin System
## Enterprise V1.1 — Phase 1 RC1

第一階段核心修正版：

- Dashboard 今日營運資訊
- 房況日曆穩定載入
- 房間層級衝突檢查
- 舊版 LocalStorage 資料自動轉換
- 舊資料首次啟動自動備份
- 模組錯誤隔離，單一錯誤不再中斷整套系統

### 使用
解壓縮後開啟 `index.html`。

帳號：`admin`  
密碼：`123456`

### 第一階段驗收
1. 首頁 KPI 是否正常。
2. 房況日曆是否出現完整月份格線。
3. 上月、下月及今天按鈕是否正常。
4. 拖曳訂單是否能調整日期。
5. 日期或房間衝突時是否阻止變更。
6. 關閉重開後資料是否保留。


## RC3 更新摘要

- Dashboard 每日營運中心、待發 LINE、埔里即時天氣。
