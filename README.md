# Meiyuan6 Booking Admin System
## Enterprise V1.2 — Build 1

眉原六民宿訂房、入住、退房與房務管理的本機版後台系統。

## Build 1 核心功能
- 訂單管理新增「入住」與「退房」操作。
- 完成入住後，訂單狀態同步為「已入住」。
- 完成退房後，每個住宿單位自動建立「待清掃」房務任務。
- 房務狀態流程：待清掃 → 清掃中 → 待複查 → 已完成。
- 清掃開始與完成時間自動記錄。
- 房務管理顯示入住中、待清掃、清掃中、可入住數量。
- 房況日曆同步顯示當日未完成房務工作。
- Dashboard 同步顯示今日入住、今日退房與待清潔數量。
- 保留 RC3.2.4 的早餐送餐天數、模板新增刪除及 iPad LINE 路由修正。

## 使用方式
1. 解壓縮 ZIP。
2. 建議透過本機 Web Server、Cloudflare Pages 或 Netlify 開啟。
3. 測試帳號：`admin`
4. 測試密碼：`123456`

## 資料保存
資料保存在目前瀏覽器的 LocalStorage。不同裝置及不同瀏覽器不會自動同步。正式營運前請定期使用「系統設定 → 資料管理 → 匯出完整備份」。

## 建議驗收流程
1. 新增一筆今日入住訂單。
2. 在訂單管理按「✅ 入住」。
3. 再按「🚪 退房」。
4. 確認自動跳到房務管理並建立每個房間的待清掃工作。
5. 依序按「開始清掃／更新狀態」，直到已完成。
6. 確認該房間恢復為「可入住」。
