# 部署與啟用
1. 將 ZIP 解壓後推送至 GitHub `meiyuan6-official` main 分支，或由 Netlify 連結該 Repository。
2. Netlify Site configuration → Identity → Enable Identity。
3. Registration 設為 Invite only。
4. Services → Git Gateway → Enable。
5. 邀請 `liou20251023@gmail.com`。
6. 開啟 `/admin/` 登入並測試草稿、發布、圖片上傳。
7. 確認正式網址、robots.txt、sitemap.xml、404 與行動版。

注意：ZIP 本身不能代替 Netlify/GitHub 帳號內的授權操作。
